# Documentation website design reference

This folder is a source-owned design proposal, not the public website, desktop application, extension, production component implementation, or runtime evidence. Independent review is required before implementation.

Open `reference.html` locally. Its adjacent CSS and JavaScript are the complete preview dependencies; it makes no network calls, loads no external font or image, accepts no private files, and invokes no product action. Example deterministic selector: `reference.html?screen=home&theme=dark&language=bilingual&state=baseline`. Hash routes support navigation and `#article/review` article anchors. The selected viewport and display scale are external capture conditions, never simulated by changing the page's font size.

## Files

- `reference.html`, `reference.css`, `reference.js`: reference-only page geometry, type hierarchy, color roles, navigation and bounded interactions.
- `inventory.json`: handwritten routes, screen/element states, responsive tuples, component registration requirements and accepted reference limitations.
- `handoff.md`: production architecture, complete content rules, static boundary, privacy, feature coverage and acceptance requirements.

## Baseline and verdict

The design baseline is source `8dbc7f23ea77070297b10c91adc674d8b9740d95`. Statements about existing work are attributed to that source's README, HANDOFF and categorized documentation. They are bounded historical reports, not independently repeated checks. No verified installer release, public deployment, homepage readback, complete wiki inventory, production visual parity, or runtime acceptance is asserted here.

The reference has working hash navigation, light/dark presentation, three language preview modes, collection-title filtering, clear-search action, article disclosure and internal anchor links. Deep settings, comprehensive localization, registered production Material Web components, full tab management, complete article rendering, regex editing, privacy imports and all wider universal features are explicitly unimplemented by this reference. Its semantic HTML represents specification-backed design compositions; it is not evidence that generic HTML can replace registered Material Design 3 production components.
