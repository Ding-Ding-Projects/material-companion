# Documentation website

The public website is independently readable documentation and project status. It does not imitate the desktop workspace. The optional installed extension and native pairing remain an approved separate integration.

- [Reading, search and preferences](reading-and-preferences.md)
- [Acceptance inventory and known gaps](acceptance.md)

All articles below `docs/` are embedded in each website build. Article language is preserved; complete Cantonese article translations remain pending. There is no project HTTP API exposed by this static website, so a Postman collection is not applicable.
